Schermo nero o rosso all'avvio

  1. Tieni premuto il tasto di accensione per 10-20 secondi.
  2. Togli la scheda e guarda la cartella Arcade/Logs: avvio.log, sistema.txt e Arcade.log descrivono cosa è successo.
  3. Se la scheda è danneggiata, riscrivi l'immagine. Prima copia sul computer i tuoi salvataggi.

Un gioco non parte

  • Il messaggio Il core non ha caricato la ROM indica file mancanti o una raccolta di ROM diversa da quella richiesta: vedi Caricare i giochi.
  • Esegui Verifica ROM e apri la scheda del gioco: indica cosa manca, compreso un BIOS.
  • I giochi Neo Geo hanno bisogno di neogeo.zip in Arcade/Bios.

Un gioco è lento o l'audio gracchia

  • Prova il profilo Prestazioni in Impostazioni → Giochi.
  • Alcuni arcade 3D sono troppo pesanti per queste console o non sono supportati dagli emulatori inclusi.
  • Prova la stessa ROM con l'altro emulatore, se c'è in entrambi.

Il computer chiede di formattare la scheda

Rispondi di no. La scheda contiene partizioni di avvio che il computer non sa leggere: è normale. Quella con i tuoi file si chiama ARCADE.

File rovinati o errori strani dopo la copia

Schede e lettori economici possono rovinare i file senza dare errori. Prova un altro lettore e, se il problema resta, un'altra microSD.

Le copertine non si scaricano

Controlla che il Wi-Fi sia collegato e che data e ora siano giuste. Alcuni giochi poco noti possono non avere immagini.

Serve più dettaglio

Aumenta il livello in Impostazioni → Strumenti → Registro diagnostico, riproduci il problema e guarda i file in Arcade/Logs.
