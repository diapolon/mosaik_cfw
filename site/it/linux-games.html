Mosaik può avviare giochi nativi compilati per la console (Linux ARM a 64 bit). Non tutti funzioneranno: dipende da come è stato preparato il gioco.

Come si aggiunge un gioco

Crea una cartella in Arcade/Linux, con dentro il gioco e un file launch.sh che lo avvia:

Arcade/Linux/MioGioco/
    launch.sh      obbligatorio: avvia il gioco
    game.json      facoltativo: titolo e opzioni
    cover.png      facoltativo: copertina

Il file game.json

{
  "title": "Il mio gioco",
  "year": "2024",
  "author": "Autore",
  "env": { "NOME_VARIABILE": "valore" },
  "keys": { "A": "SPACE", "START": "ENTER" }
}
title, year, authorCompaiono nella libreria e nella scheda del gioco.
envVariabili d'ambiente impostate prima di avviare il gioco.
keysPer i giochi che non leggono i controller: ogni tasto della console preme il tasto della tastiera indicato.

Durante il gioco

Tieni premuto Menu per 1 secondo per il menu con riprendi, volume, luminosità ed esci. La sospensione con il tasto di accensione funziona anche qui.

Se qualcosa non va

Quello che il gioco scrive finisce in Arcade/Logs/linux-games.log.
