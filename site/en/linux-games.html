Mosaik can start native games built for the console (64-bit ARM Linux). Not all of them will work: it depends on how the game was prepared.

Adding a game

Create a folder in Arcade/Linux with the game and a launch.sh file that starts it:

Arcade/Linux/MyGame/
    launch.sh      required: starts the game
    game.json      optional: title and options
    cover.png      optional: cover

The game.json file

{
  "title": "My game",
  "year": "2024",
  "author": "Author",
  "env": { "VARIABLE_NAME": "value" },
  "keys": { "A": "SPACE", "START": "ENTER" }
}
title, year, authorShown in the library and on the game's details page.
envEnvironment variables set before the game starts.
keysFor games that don't read controllers: each console button presses the given keyboard key.

During the game

Hold Menu for 1 second for the menu with resume, volume, brightness and exit. Sleep with the power button works here too.

If something goes wrong

What the game prints goes to Arcade/Logs/linux-games.log.
