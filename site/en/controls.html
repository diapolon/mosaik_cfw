Everywhere

ButtonWhat it does
Power, short pressPuts the console to sleep, even during a game. Press again to wake it and the game continues where it was.
Power, heldAfter a couple of seconds it asks whether to power off. During a game it saves and powers off.
Volume + / −Change the volume, with an on-screen bar even in games.

In the launcher

ButtonWhat it does
AOpen, confirm, start the game
BBack
XGame details
YAdd to or remove from favorites
StartSettings
SelectFilters and sorting (in the library)
L / RSwitch tabs in the library

In arcade games

Press Menu to open the game menu: resume, save and load state, aspect ratio, video filter, bezel, screen rotation, game options, controls, restart, exit. To leave the game choose Exit to menu.

Shortcuts (hold Menu)

CombinationWhat it does
Menu + RSave state
Menu + LLoad state
Menu + R2Fast forward
Menu + XScreenshot
Menu + Up / DownVolume
Menu + Left / RightBrightness

From the menu's Controls item you can choose which console button each game control uses, for that game only.

In Linux games

Hold Menu for 1 second: a menu appears over the paused game with resume, volume, brightness and exit. B or Menu resume the game.
