Mosaik is made of many components by different authors, each with its own license. Here you can see what they are, read the license texts and find the sources. The same texts are on the card, in the Arcade/Licenses folder.

Mosaik

The launcher, themes, menus and system scripts. The code written for Mosaik is distributed under the GNU LGPL v3, which builds on the GNU GPL v3. The source code is at github.com/diapolon/mosaik_cfw. The license does not apply to the third-party components listed below.

Proprietary components

To make the console work, Mosaik also uses these components of the official firmware. They belong to their respective owners and are not covered by the licenses listed above:

  • PowerVR graphics drivers (EGL and OpenGL ES libraries, pvrsrvkm module, rgx firmware)
  • trimui_inputd (button handling)
  • Firmware for the XR829 Wi-Fi and Bluetooth chip
  • The first stage of the console's boot (boot0)
